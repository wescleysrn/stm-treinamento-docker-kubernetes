# Prática: Certificado SSL Autoassinado e Configuração de Trust (CA)

Nesta aula prática, aprenderemos a gerar um certificado SSL autoassinado do tipo **Wildcard (`*.stmcurso.com.br`)** com suporte a **SAN (Subject Alternative Name)**. Isso permitirá que múltiplos serviços (como `nexus.stmcurso.com.br`, `sonar.stmcurso.com.br`, etc.) utilizem o mesmo certificado em nosso servidor proxy Nginx.

---

## 1. Pré-requisitos

Certifique-se de ter o **OpenSSL** instalado e configurado no seu ambiente terminal (PowerShell no Windows, Bash no Linux/macOS ou via WSL).

```
https://openssl-library.org/source/
```

Adicionar no path do sistema.

Devemos criar uma pasta de destino para os certificados gerados, como exemplo:

```
F:\DockerKubernete\ssl
```

---

## 2. Passo a Passo: Gerando o Certificado SSL Wildcard (Com SAN)

Para navegar por subdomínios sem erros de validação moderna de navegadores (Chrome/Edge/Firefox exigem o campo `subjectAltName`), vamos criar o certificado com suporte ao wildcard.

### Passo 2.1 — Criar a Chave Privada (Private Key)
Geramos uma chave privada RSA de 2048 bits:

```bash
openssl genpkey -algorithm RSA -out stm_curso_private_key.key -pkeyopt rsa_keygen_bits:2048
```

### Passo 2.2 — Criar o Arquivo de Configuração OpenSSL com SAN (openssl-san.cnf)

Crie um arquivo chamado openssl-san.cnf no mesmo diretório com o conteúdo:

```ini, toml
[req]
default_bits       = 2048
default_keyfile    = stm_curso_private_key.key
distinguished_name = req_distinguished_name
req_extensions     = v3_req
prompt             = no

[req_distinguished_name]
C  = BR
ST = Brasilia
L  = Brasilia
O  = STM - Superior Tribunal Militar
OU = Capacitacao
CN = stmcurso.com.br

[v3_req]
keyUsage = critical, digitalSignature, keyEncipherment
extendedKeyUsage = serverAuth
subjectAltName = @alt_names

[alt_names]
DNS.1 = stmcurso.com.br
DNS.2 = *.stmcurso.com.br
```

### Passo 2.3 — Gerar a Solicitação de Assinatura (CSR)

Com o arquivo de configuração pronto, gere a CSR:

```bash
openssl req -new -key stm_curso_private_key.key -out stm_curso.csr -config openssl-san.cnf
```

### Passo 2.4 — Gerar o Certificado Autoassinado (CRT)

Gere o certificado final (válido por 10 anos / 3650 dias):

```bash
openssl x509 -req \
  -in stm_curso.csr \
  -signkey stm_curso_private_key.key \
  -out stm_curso.crt \
  -days 3650 \
  -extensions v3_req \
  -extfile openssl-san.cnf
```

```bash
openssl x509 -req -in stm_curso.csr -signkey stm_curso_private_key.key -out stm_curso.crt -days 3650 -extensions v3_req -extfile openssl-san.cnf
```

> Resultado:
> stm_curso_private_key.key: Chave privada do SSL.
> stm_curso.crt: Certificado público SSL/TLS.


## 3. Instalando o Certificado no Sistema Operacional (Confiabilidade)

Para evitar os alertas de "Sua conexão não é segura" no navegador:

### Windows (PowerShell Administrador)

Pressione Win + R, digite certlm.msc e pressione Enter.

Navegue até Autoridades de Certificação Raiz Confiáveis > Certificados.

Clique com o botão direito na pasta Certificados > Todas as Tarefas > Importar....

Selecione o arquivo stm_curso.crt e conclua o assistente.

### Linux (Debian/Ubuntu)

```bash
sudo cp stm_curso.crt /usr/local/share/ca-certificates/stm_curso.crt
sudo update-ca-certificates
```

### Linux (RHEL/CentOS/Fedora)

```bash
sudo cp stm_curso.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust extract
```
