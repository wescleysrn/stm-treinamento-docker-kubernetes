# Documentação de temas base úteis e bons

Uma documentação de FSE Block Themes usando [Filtros na Busca Oficial](https://pt.wordpress.org/themes/) indicando Feature = Block Themes e Subject = Educação e E-Commerce.

## Online Learning

O tema [Online Learning](https://wordpress.org/themes/online-learning/) é um tema gratuito e popular para sites de cursos online. Ele é compatível com o plugin LearnPress e oferece uma variedade de recursos para criar uma plataforma de aprendizado online.
Podemos acessar o [Exemplo online](https://onlinelearning.thimpress.com/)
