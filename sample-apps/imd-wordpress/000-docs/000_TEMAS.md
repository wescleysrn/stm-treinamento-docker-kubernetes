# Temas WordPress

Os temas no WordPress podem ser classificados por diversos aspectos, desde sua finalidade ou proposito, se aplicados para e-commerce, sites educacionais, gerando uma forte dependência do plugin com o tema ou também se ele é pago ou não, otimizado ou não.
Para fins de documentação deste topico será descritos de forma superficial os temas que mais se mostraram promissores.
